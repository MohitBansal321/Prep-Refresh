# JavaScript Fundamentals

Workflow for teaching/revising JS fundamentals:

1. **Identify the topic** from the user's question
2. **Load the relevant reference** file below
3. **Explain** the concept with a concise definition
4. **Demonstrate** with a minimal runnable code snippet
5. **Quiz** the learner with a quick challenge (if they want practice)

## Topic Map

## Key Teaching Principles

- Always show **runnable code** with expected console output in comments
- Highlight **common gotchas** (e.g. `typeof null === "object"`, `NaN !== NaN`)
- When comparing concepts, use a quick **comparison table**
- End explanations with a **"Try it yourself"** mini-exercise when appropriate
